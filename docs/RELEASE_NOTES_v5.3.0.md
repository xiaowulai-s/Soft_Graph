# SoftGraph v5.3.0 —— 备份同步 · 插件 API v2 · 沙箱 · 界面精修

发布日期：2026-11-07

## 新功能

### N1 备份同步（独立页面）
- 开发文件夹 → 移动硬盘 增量备份：多个源目录、按卷标识别目标盘（备用盘符兜底），换 USB 口不影响识别
- **只增不改不删**：目标端已有文件一律不覆盖 —— 相同（尺寸+修改时间）跳过，不同记冲突，首版不做删除同步
- **拔盘暂停、插回续传**：运行中每 5s 探活，目标盘移除自动暂停，重新接入自动续传；也可手动暂停/续传/停止
- 任务日志（最近 200 条）+ 实时进度推送（新增/跳过/冲突/字节数/当前文件）

### S3b 插件 API v2：点击动作 +「我的应用」卡
- 数据项新增 `action` 字段（`open-path` / `open-url`），带动作的行在浮窗上可直接点击
- 安全设计：渲染层只上报「插件 id + 行号」，target 由主进程从净化工件回查 —— 渲染层伪造不了路径；`open-url` 仅接受 https
- 新内置插件 **sg.apps「我的应用」**：点击即启动（最近启动优先、已收录软件补齐），默认启用

### A1 插件沙箱（渐进式）
- 外部插件改在 **node:vm 隔离上下文**中加载与执行：无 process/Buffer，require 白名单（path/os/url），需要系统能力走 ctx（受 F1 授权约束）
- collect 同步死循环会被沙箱超时打断，不再可能卡死主进程
- 诚实边界：纵深防御而非硬安全边界，强隔离（子进程）留待生态扩大后评估

### 界面精修（参考大厂风格）
- 侧栏重设计：208px 宽、active 改淡色胶囊（替代整块色底）、品牌位圆角标、统一 hover/过渡
- 全局令牌补充：层级阴影（sm/md）、焦点环、统一过渡曲线；primary 按钮悬停微升
- 页面骨架升级：更大的页头层级、卡片悬停微升、空态虚线卡

## 改进

### C2 winget 模块化（v3.x 遗留观察项闭环）
- winget 调用从 scan.ts 抽离为独立 `services/winget.ts`：GBK 解码 / id 白名单 / 参数契约 / 退出码解读全部收敛一处，纯函数单测锁定行为，后续迁官方模块只动一个文件
