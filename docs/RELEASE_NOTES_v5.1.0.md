# v5.1.0 Release 发布说明

**发布日期**：2026-11-07 · **tag**：`v5.1.0` · 测试 500/500 全绿 · 真机 CDP 冒烟通过

## 本版主题：功能梳理落地 + 浮窗「不显示」根因修复

按《docs/15-功能梳理与新功能规划》第一批实施。

### 🔴 修复：浮窗「开了不显示」（根因确诊）

**根因**：默认创建位置距屏幕右缘 24px，小于贴边判定阈值 28px——浮窗一出生就被判定「已贴边」并立即自动隐藏，只留下 6px 的触发条，肉眼等于不存在。窗口其实一直在（调试协议可见），只是视觉上完全隐藏。

**修复**：
1. 默认创建位置改为距右缘 40px（不再落入贴边判定区）
2. **首次启用不再自动隐藏**——先让浮窗本体完整显示，并发系统通知告知「之后会贴边隐藏，鼠标移到屏幕边缘唤出」
3. 补齐观测：渲染加载失败 / 渲染进程退出 / ready-to-show 超时（10s 兜底强制显示）全部写日志

### 功能布局调整（IA 四项）

| 调整 | 内容 |
|---|---|
| 清理 = 磁盘治理大本营 | 头部工具区新增「🖼 相似图片」入口（与空间树图并列） |
| 工具箱 = 软件管家 | 新增「装机清单」行；「规则供给」迁出到设置 |
| 图谱 = 动作中枢 | 软件菜单新增「检查升级」（winget 名称匹配 + 一键升级）与「卸载引导」（拉起系统卸载向导，仅对登记了卸载串的软件显示） |
| 设置补全 | 新增「规则供给」（更新源 + 在线检查）与「备份」（导出/导入设置）两个分节 |

### 新功能

- **GC-19 安装包残留**（规则包 v7）：下载目录 30 天前的 setup/msi/installer 类安装包，hint 级默认不勾选；老用户经规则热更新即可收到
- **仪表盘**：新增「常用软件」区（最近启动一键再启）+「可升级软件 N 个」动态行（懒加载）
- 修复：软件列表 ▶ 启动 / 装机清单导出的事件接线缺失（v4.1 遗留，点击无效）

### 升级

5.0.0 → 5.1.0：应用内 ⟳ 或系统通知 → 下载 → 重启并安装。装后建议：设置 → 浮窗 → 开启浮窗，即可看到修复后的完整体验（首次不隐藏 + 引导通知）。
