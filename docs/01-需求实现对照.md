## 2.2 非功能需求

| 类别 | 指标要求 | 实测 / 说明 |
|---|---|---|
| 性能 | 冷启动到首屏 ≤ 3s | ✅ 先渲染 SQLite 缓存的软件清单，扫描结果异步回填 |
| 性能 | 软件清单枚举 ≤ 5s | ✅ v2.0.0 M1 达标：**11.06s → 4.46s**（PowerShell 常驻会话池 + 便携扫描 worker 池 + 已安装解析并发化）。v1.0.0 期为 19~28s |
| 性能 | 单软件图谱构建（缓存命中）≤ 400ms | ✅ SQLite 直查 + 坐标缓存复用（实测 **1ms**） |
| 性能 | 单软件图谱构建（冷启动）≤ 3s | ⚠️ 小软件 ~0.2s；超大型目录仍超 3s。**v3.0.0 A7 后**（同机同输入 5 样本）：依赖解析总耗时 **30701ms → 9881ms（−68%）**，单软件 60ms ~ 6.4s（Siemens NX 38.88GB）；瓶颈从「E4 定位缺陷 + 串行快照」变为快照占 63.9% |
| 性能 | 全盘垃圾扫描（100 万文件）≤ 120s | ✅ v2.0.0 M1 达标：**106.81s → 44.98s**（GC-12 −74% / GC-11 −59%）；v3.0.0 A4 再降 48% |
| 性能 | 增量扫描 ≤ 5s | ⚠️ **未达成（已定稿）**：USN 两级增量均已落地，但变更记录无路径 ⇒ 目录级定向失效不可行；「父文件 ID 反查」实测单次 158ms × 200 条 = 31.6s（签名遍历基线的 316%），已明确放弃。当前走「卷哨兵 → USN 零变更复用 → 目录签名」三级降级 |
| 性能 | 图谱交互 60 FPS | ✅ 布局计算在 Web Worker；>1500 节点切 Canvas + 视口裁剪 + 标签 LOD |
| 可靠性 | 扫描崩溃可重启续扫、删除原子可回滚 | ⚠️ 删除具备三重校验 + 隔离区回滚；扫描进程隔离降级（见差异） |
| 安全性 | 白名单硬拦截、隔离区默认、多重确认 | ✅ `packages/shared/safety.ts` 纯函数硬编码白名单；详见 README 安全章节 |
| 兼容性 | Win10 1809+ / Win11，x86 兼容（WOW64） | ⚠️ 目标兼容（DLL 搜索按目标程序位数选 System32/SysWOW64），**仅在 Win11 23H2 实测** |
| 资源占用 | 内存 ≤ 400MB（常规） | ⚠️ Electron 基线内存约 150~250MB + sql.js 整库内存；超大图谱时偏高 |
| 可维护性 | 规则 JSON 配置驱动、扫描层接口与平台实现分离 | ✅ 规则热更新（改文件重启生效）；PE 解析 / DLL 解析 / 安全规则均为独立可替换模块 |
| 易用性 | 零配置首扫、删除可撤销 | ✅ 首次启动自动探测常见目录；隔离期内 100% 可还原 |

## 已知差距与后续排期

| 差距 | 影响 | 计划 / 现状 |
|---|---|---|
| 增量扫描未达 ≤5s | 二次扫描无法秒级完成 | **已定稿为降级**：卷哨兵 + `reuse-all` + 目录签名三级（v3.0.0 实测 38.7s → 10.8s）；`partial` 因反查成本（单次 158ms、无批量）明确放弃 |
| 软件清单枚举超时 | 首次体验略慢 | ✅ 已解决（v2.0.0 M1：11.06s → 4.46s） |
| 未做 Win10 回归 | 兼容性未知 | ⏳ 仍缺 Win10 测试机（`docs/08-v3.0.0-开发计划.md` C1）；已有自动化冒烟脚本待命 |
| 未做代码签名 | 杀软可能误报（风险 R8） | ⏳ 流水线已用自签名验证通过（`docs/07-代码签名.md`），等 OV/EV 证书到位后 15 分钟切换 |
| 规则库在线更新 | 目前需手工改文件 | ✅ 已实现：HTTPS + Ed25519 签名 + SHA-256 + 版本单调 + 结构安全校验（21 用例覆盖） |
