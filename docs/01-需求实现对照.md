## 2.2 非功能需求

| 类别 | 指标要求 | 实测 / 说明 |
|---|---|---|
| 性能 | 冷启动到首屏 ≤ 3s | ✅ 先渲染 SQLite 缓存的软件清单，扫描结果异步回填 |
| 性能 | 软件清单枚举 ≤ 5s | ⚠️ 本机实测 **19~28s**（含便携软件目录扫描与图标提取；PowerShell 冷启动约 0.3~0.6s/次）。未达文档指标，原因见「已知差距」 |
| 性能 | 单软件图谱构建（缓存命中）≤ 400ms | ✅ SQLite 直查 + 坐标缓存复用 |
| 性能 | 单软件图谱构建（冷启动）≤ 3s | ⚠️ 小软件 ~0.2s；超大型目录（Siemens NX 11.75GB / 6027 依赖）约 17s |
| 性能 | 全盘垃圾扫描（100 万文件）≤ 120s | ⚠️ 本机全量实测 ~160s（含重复文件全文件 SHA-256 复核） |
| 性能 | 增量扫描 ≤ 5s | ❌ 依赖 USN，一期未实现 |
| 性能 | 图谱交互 60 FPS | ✅ 布局计算在 Web Worker；>1500 节点切 Canvas + 视口裁剪 + 标签 LOD |
| 可靠性 | 扫描崩溃可重启续扫、删除原子可回滚 | ⚠️ 删除具备三重校验 + 隔离区回滚；扫描进程隔离降级（见差异） |
| 安全性 | 白名单硬拦截、隔离区默认、多重确认 | ✅ `packages/shared/safety.ts` 纯函数硬编码白名单；详见 README 安全章节 |
| 兼容性 | Win10 1809+ / Win11，x86 兼容（WOW64） | ⚠️ 目标兼容（DLL 搜索按目标程序位数选 System32/SysWOW64），**仅在 Win11 23H2 实测** |
| 资源占用 | 内存 ≤ 400MB（常规） | ⚠️ Electron 基线内存约 150~250MB + sql.js 整库内存；超大图谱时偏高 |
| 可维护性 | 规则 JSON 配置驱动、扫描层接口与平台实现分离 | ✅ 规则热更新（改文件重启生效）；PE 解析 / DLL 解析 / 安全规则均为独立可替换模块 |
| 易用性 | 零配置首扫、删除可撤销 | ✅ 首次启动自动探测常见目录；隔离期内 100% 可还原 |

## 已知差距与后续排期

| 差距 | 影响 | 计划 |
|---|---|---|
| 无 USN Journal 增量 | 二次扫描无法秒级完成 | 后续接入 Rust 原生层或 `node-gyp` 扩展（M2） |
| 软件清单枚举超时 | 首次体验略慢 | 并行化 PowerShell 采集、图标提取改为懒加载（M1） |
| 未做 Win10 回归 | 兼容性未知 | 建立 Win10 22H2 / Win11 23H2 双基线（M3） |
| 未做代码签名 | 杀软可能误报（风险 R8） | 购买/申请证书后签名（M4） |
| 的规则库在线更新 | 目前需手工改文件 | HTTPS + 签名校验的更新通道（M4） |
