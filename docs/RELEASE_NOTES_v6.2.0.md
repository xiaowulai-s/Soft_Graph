# SoftGraph v6.2.0 —— 备份 v2 审阅式镜像

发布日期：2026-11-08

## 备份同步全面重构（v1 → v2）

### 关键修复
- **U 盘检测不到（根因修复）**：设备查询脚本误用 PowerShell 7 的 `??` 运算符，Windows PowerShell 5.1 解析报错导致设备列表永远为空。已改 5.1 兼容写法；设备条增加 5 秒自动轮询 + 手动刷新
- **选目录后不回填 / 表单输入不同步（根因修复）**：Input 组件改用 Vue `defineModel` 标准实现，v-model 单双向均正确

### 同步引擎重做：审阅式
- 「预览差异」生成差异报告：**新增 / 更新覆盖 / 目标多出 / 一致** 四区统计（含字节数）+ 每区最多 200 条采样明细
- 冲突不再静默跳过：确认策略后**以源为准单向覆盖**；「目标多出」审阅后删除（不勾选则永不删除）
- 执行前目标盘**容量预检**；预览支持**取消**（带进度显示）

### 路径映射双模式
- **显式「源→目标」映射对**（默认）：如 `D:\Demo → E:\Demo`，兼容手动拷贝的目录结构
- **盘符镜像**：`D:\work\app` 自动落到目标盘 `X:\D\work\app`

### 其他
- **排除规则**：默认 15 类（node_modules / .git / dist / cache…）+ 自定义追加
- **定时自动备份**：到期且目标盘在线才执行；无人值守安全策略（只新增与更新覆盖，绝不删除）
- 长路径（>260 字符）兼容、symlink 跳过、旧版任务自动迁移

## 其他

- 全部 13 页完成 Tailwind v4 + shadcn-vue 迁移（对齐设计稿，逐页差异记录 docs/DESIGN_COMPARISON_v6.1.md）
