# SoftGraph v3.1.0 —— 竞品对标新功能包

对标 GitHub 同类优秀项目（Czkawka 32.7k★ / BCU 21.8k★ / UniGetUI 26.5k★ / BleachBit 6.7k★），
把「借功能、长在自有底盘上」落成五个新能力。完整选型见 `docs/08-v3.1-开发计划.md`。

## 新功能

### 1. 定时静默清理
设置 → 清理与安全 → 「定时静默清理」：启用后按周期（每天~每两周）自动隔离清理一键白名单项，可在隔离区还原，全程审计留痕。

### 2. 软件升级管家（winget）
设置页一键列出本机可升级软件（解析 winget 输出，GBK 码页正确解码），支持单个或全部静默升级；软件 Id 白名单防注入。

### 3. 浏览器隐私数据盘点（GC-17，hint）
Chrome/Edge/Firefox 的 Cookie、历史、会话文件盘点。hint 级仅提示——清理会登出所有网站，是否清理由你决定。

### 4. 隔离区粉碎器
对隔离区内容先单遍随机覆写再删除（不可恢复），双击确认 + 审计留痕。适合清理含敏感信息的隔离副本。

### 5. Winapp2 社区规则导入
设置页导入 Winapp2.ini（社区数千条清理规则生态），每节一条规则、默认不勾选、逐项审阅后使用；幂等导入、热重载即时生效。

## 规则更新（v5）

GC-17 已入签名规则包，老用户在线更新即可收到；升级到 3.1.0 则启动自动合并。
