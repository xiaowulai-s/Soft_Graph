# SoftGraph v1.0.0

把「装了什么 / 依赖谁 / 垃圾在哪」三件事合并成一张图的 Windows 桌面工具。

以软件图标为中心节点、直线连接外围依赖文件，鼠标悬停即显示完整路径；侧边栏同步呈现磁盘垃圾分布，支持按分类删除与一键清空；另附一个可自由组合内容的桌面浮窗。

## 新增内容

### 模块一 · 软件图谱工具

**软件发现**
- 五来源枚举：注册表卸载项（HKLM/HKCU + WOW6432Node）、MSI 产品、App Paths、Microsoft Store 应用、服务宿主
- 便携软件七特征加权识别：目录自包含 +30 / 无卸载项 +20 / 本地配置 +15 / 目录可写 +10 / 无安装器痕迹 +10 / 版本资源 +10 / 用户手动标记 +100
- 支持一键纠正识别结果，纠正记录持久化

**依赖解析（技术内核）**
- 纯 TypeScript 手写 PE 解析器：导入表、延迟导入表、.NET 程序集引用、SxS 清单、版本资源
- 惰性 64KB 分页读取，可解析 222 MB 的单体可执行文件（内存占用与文件大小解耦）
- 八类依赖证据加权融合为 0~1 置信度，含多证据印证加成与共享惩罚
- Windows 三大特殊机制专门处理：API Set 虚拟 DLL 映射、KnownDLLs、WinSxS 重定向
- WOW64 位数感知的 DLL 搜索路径（x86 程序正确解析到 SysWOW64）
- 缺失依赖红色告警并给出修复建议（如提示安装对应版本 VC++ 运行库）

**图谱可视化**
- 径向分层布局 T0~T3，d3-force + 自定义角度分散力，布局计算在 Web Worker 中执行
- SVG（≤1500 节点）/ Canvas（>1500 节点）双渲染，视口裁剪 + 标签 LOD + 批量绘制
- **悬停详情浮层七区块**：标题 / 完整路径（可复制）/ 属性 / 关系 / 归属 / 安全 / 操作
- 直线连接依赖文件（非贝塞尔曲线），线宽按置信度区分，缺失依赖为红色虚线
- 缩放平移（惯性阻尼）、按类型与置信度筛选、模糊搜索定位、双击下钻、右键菜单、导出 PNG
- 复用缓存的布局坐标，二次打开无需重算

**磁盘垃圾治理**
- 13 类垃圾规则（GC-01 ~ GC-13），JSON 配置驱动，支持环境变量展开、glob 匹配、排除规则、体积与时长过滤
- 重复文件三级过滤：大小分组 → 头/中/尾各 64KB 采样哈希 → 全文件 SHA-256 复核
- 侧边栏环形图 + 分类列表 + 明细抽屉（文件名 / 完整路径 / 大小 / 修改时间）
- 按分类删除、逐项勾选删除、一键删除
- 三级确认强度：低风险单次确认 / 中风险展示影响清单 / 高风险需输入「确认删除」
- 隔离区 + manifest，保留期内可完整还原（低中 7 天 / 高 14 天）

### 模块二 · 桌面浮窗监控

- 无边框透明置顶窗口，不占任务栏、不抢焦点、可见于全屏工作区
- **靠边自动隐藏**：吸附判定 + 3px 触发条 + 鼠标移入缓动滑出 + 延迟收起
- 拖拽定位与位置持久化；宽度 / 透明度 / 紧凑模式 / 三套主题（深色、浅色、毛玻璃）
- **插件化架构**：`%LOCALAPPDATA%\SoftGraph\plugins\` 放入 `.js` 文件即扩展新卡片，支持热重载
- 内置 7 个插件（CPU 与内存、磁盘空间、网络速率、时钟日期、垃圾占用、系统概览、内存 TOP 进程），与外部插件走完全相同的契约
- 提供示例插件与开发文档

## 安全设计

- **路径白名单硬编码**：以纯函数固化在代码中，不读取配置文件，篡改设置无法绕过
  - System32 / SysWOW64 / WinSxS / Program Files 等整树禁删
  - 卷根目录、UNC 路径、系统关键文件（`pagefile.sys` 等）拦截
  - 用户桌面 / 文档 / 下载等目录本身不可删，其内部文件可清
- **删除三重校验**：白名单拦截 → `realpath` 解析防 junction 逃逸 → 删除前复核 size + mtime 防路径复用误删
- **隔离区兜底**：默认移入隔离区，保留期内可完整还原
- **一键删除边界**：仅作用于「低风险且默认勾选」的分类，中高风险必须单独确认，该规则不可通过设置关闭
- **零上传**：全部扫描、解析、统计均在本地完成

## 已知限制

| 项 | 说明 |
|---|---|
| 无增量扫描 | 基于 USN Journal 的秒级增量（FR-13）一期未实现，每次为全量扫描 |
| 平台验证 | 仅在 Windows 11 23H2 实测，Windows 10 未做回归 |
| 未代码签名 | 杀软可能误报 |
| 部分权重证据 | COM 注册反查（E6）默认关闭以保图谱构建速度；ETW 运行时证据（E8）预留 |
| 受保护目录 | WinSxS、SoftwareDistribution 等受 TrustedInstaller 保护的对象不接管所有权，仅检测并提示 |

## 快速上手

1. 运行程序，点顶栏「扫描软件」，等待约 20~30 秒
2. 左侧点选任一软件，中间自动构建依赖图谱
3. 鼠标移到任意文件节点查看完整路径与属性
4. 右侧点「开始扫描」查看垃圾分布，勾选后「分类删除」或「一键删除」
