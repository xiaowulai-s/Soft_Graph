# SoftGraph v3.2.0 —— 决策清单 14 项全落地

基于《09-改进决策清单》审计，14 项改进全部按建议方案实施。分组规则模型是本版核心。

## 🔴 结构性修复（第一批）

- **规则分区模型（A1）**：运行时规则 = 内置（随应用）⊕ 社区区 ⊕ 用户区。内置规则不再落盘——彻底根除「本地文件遮蔽内置新规则」这一贯穿 v3.0~3.1 的结构缺陷；Winapp2 导入与在线更新都写入社区区，**可整体重导更新**；旧合并文件里的社区规则首启自动迁移（旧文件改名 `.legacy` 备份）
- **哈希即真相（A2）**：规则内容比对改用**语义哈希**（排序键稳定序列化，对键序/换行/空白不敏感，非法 JSON 退化原文哈希）；在线更新前先比哈希，内容一致直接跳过，不再产生误导性更新记录
- **浏览器保护（B1）**：清理含浏览器隐私项（GC-17）时自动检测 chrome/msedge/firefox 进程，运行中则跳过并提示，防止损坏 Cookie/会话
- **winget 提权重试（C1）**：升级失败自动识别「需管理员」类错误，列表标记并提供 UAC 提权重试

## 第二批

- **自定义扫描目录（B2）**：维护中心可添加 GC-11 重复文件 / GC-12 超大文件的额外扫描目录
- **逐条粉碎（B3）**：隔离区管理页列出全部条目，勾选逐条粉碎
- **社区规则折叠分组（B4）**：扫描侧栏将 Winapp2 导入规则收进独立折叠组，不再平铺爆炸
- **应用更新双源（D1）**：GitHub 失败自动切 Gitee 镜像（stable tag，需维护者同步），再失败还原官方源

## 第三批

- **跳过此版本（D2）**：更新提示可跳过，同版本不再打扰；更新日志预览
- **签名色标（E1）**：文件卡片签名状态着色（绿=已签名/灰=未签名/红=异常）
- **定时清理可观测（E2）**：维护中心显示上次自动清理的时间/项数/释放量
- **bench 性能场景（E3）**：模拟 500 条社区规则的编译成本量化
- **发布前手测清单（F-b）**：`docs/10-发布前手测清单.md`

## 备注

- C2（winget 模块化）：官方 Client 模块成熟度不足，本版以文本解析 + 健壮性测试锁定，待模块稳定再迁移
