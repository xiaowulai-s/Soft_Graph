# v3.1 开发计划 —— 新功能路线（竞品对标选型）

> 依据 2026-10-17 竞品调研（Czkawka 32.7k★ / BCU 21.8k★ / UniGetUI 26.5k★ / BleachBit 6.7k★ / WinDirStat / privacy.sexy），
> 按性价比排定优先级。原则：**借功能、长在自有底盘上**（软件图谱 / 规则签名热更新 / 隔离区审计 / AI IDE 专项）。

## 优先级总表

| 优先级 | 功能 | 借鉴自 | 范围界定 | 验收标准 | 工作量 |
|---|---|---|---|---|---|
| **P0-1** | 定时静默清理 | UniGetUI 调度 | 设置新增 `junkSchedule`（enabled / intervalHours）；到期后自动扫描 defaultSelected 分类并隔离清理；审计留痕；设置页开关 + 上次运行时间 | 到期触发一次自动清理并写入审计与日志；间隔内不重复触发 | 小 |
| **P0-2** | 应用升级管家（winget） | UniGetUI | 主进程 `winget upgrade` 解析（GBK 解码复用）→ IPC → 设置抽屉「软件升级」区块：列表 + 单个/全部升级（静默参数） | 列出本机可升级软件；单个升级可执行并回传结果；winget 不存在时给出明确提示 | 中 |
| **P0-3** | 隐私清理（GC-17，hint） | BleachBit | 浏览器 Cookie/History/Session（Chrome/Edge/Firefox User Data 层级）；hint 级、默认不勾选、描述明示「会登出网站」 | 本机实测命中浏览器隐私文件；契约测试固化 hint + 默认不勾选 | 小 |
| **P0-4** | 隔离区粉碎器 | BleachBit | 对隔离区批次执行单遍随机覆写后删除；设置页隔离区管理加「彻底粉碎」按钮 | 粉碎后文件不可恢复（覆写+删除）；审计记录 | 小 |
| **P1-1** | Winapp2 社区规则导入 | BleachBit/FluentCleaner | 解析 Winapp2.ini（FileKeyN/ExcludeKeyN/%VARS%）→ 生成 GC-101~GC-999 规则（默认不勾选、medium）；设置页导入按钮；规则 id 校验放宽到三位 | 导入样例 ini → 编译成功 → 扫描命中 → 二次导入幂等 | 中 |
| **P1-2** | 信任色标 | BCU | 图谱/文件详情按 `signStatus` 着色（已签名=绿 / 未签名=灰 / 异常=红） | 图谱节点与详情抽屉显示签名色标 | 小 |
| **P2-1** ✅ | 相似图片清理（pHash/aHash） | Czkawka | nativeImage aHash + 并查集分组；维护中心「相似图片」标签页；删除走回收站 | v3.3.0 已交付 | 中 |
| **P2-2** ✅ | 注册表残留清理 | BCU | 卸载表死条目（卸载程序+安装目录均消失）；HKCU 直删 / HKLM UAC；仅限卸载表内键 | v3.3.0 已交付 | 中 |
| **P2-3** ✅ | 空目录检测 | Czkawka | GC-18（hint，emptydir 算法，只报最浅层空树根）；死链已有 GC-13 | v3.3.0 已交付 | 小 |

## 本轮实现范围

P0 全部（定时清理 / 升级管家 / 隐私清理 / 粉碎器）+ P1-1（Winapp2 导入）+ P1-2（信任色标）→ **v3.1.0**；
P2 三项入 v3.2 储备（另行排期）。

## 实施顺序与提交粒度

1. P0-3 隐私清理（规则级，最小改动热身）
2. P0-4 粉碎器（独立 API + UI 按钮）
3. P0-1 定时清理（调度器 + 设置 + 审计）
4. P1-2 信任色标（UI 呈现）
5. P0-2 升级管家（winget 服务 + IPC + UI）
6. P1-1 Winapp2 导入（解析器 + id 校验放宽 + UI）
7. 统一测试 → 版本 3.1.0 → 打包发布
