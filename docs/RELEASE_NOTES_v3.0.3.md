# SoftGraph v3.0.3 —— 应用本体自动更新

从本版起，**应用可以自己更新自己**（electron-updater 路线），无需再来手动下载安装。

## 应用更新如何工作

- 启动后 30 秒静默检查一次，之后每 24 小时一次；设置 → 清理与安全 → 「检查应用更新」可手动触发
- 发现新版本 → **不自动下载**（尊重流量），UI 提示后你点「下载」→ 进度可见 → 点「重启并安装」完成
- 即使没点安装，退出应用时也会自动装上（兜底）
- 下载走系统代理；签名公钥/校验链与规则更新同一套安全思路

> 注意：本版（3.0.3）需要手动安装这一次——装完它，以后的版本就都是自动的了。

## 规则更新（v3.0.2 已有）回顾

- 更新源留空 = 全自动（官方源 + jsDelivr 镜像自动回退）
- GC-16「AI IDE 缓存」：Trae/Cursor/WorkBuddy/Qoder/ZCode/Codeium 等的缓存清理（实测 411MB 级）

## 其他

- publish-release 流水线补传 latest.yml + blockmap（自更新元数据）
- 测试 470/470 全绿
