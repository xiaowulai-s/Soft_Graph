# v5.0.0 Release 发布说明

**发布日期**：2026-11-07 · **tag**：`v5.0.0` · 测试 500/500 全绿 · 真机 CDP 冒烟通过

## 本版主题：冷调玻璃（Cool Glass）全新 UI —— 浅色优先的整体重设计

按《docs/14-UI重设计规范》实施：视觉、布局、交互全部换代。

### 全新外观

- **浅色优先双主题**：冷白底 `#F2F7FA` / 纯白面板 / 细蓝描边 / 青绿强调 `#0F6E56`；深色主题完整伴生（设置里一键切换）；**新装默认浅色**
- **左侧活动栏**（VS Code 式）：54px 图标栏 + 统一手绘 SVG 线性图标（home / 图谱节点族 / funnel / 工具箱 / gear，1.7px 圆头描边，激活态青绿底白标），悬停出名称提示
- **设计签名**：0.5px 极细描边、分隔线代替卡片框、数字/路径/版本一律等宽字体

### 全新信息架构

| 区 | 内容 |
|---|---|
| **仪表盘**（默认首页） | 四指标卡（磁盘可释放 / 已收录软件 / 自启动项 / 隔离区）+ 快捷动作排 + 系统动态 |
| **软件图谱** | 三栏（列表 / 画布 / 检查器）保持，配色换冷调 |
| **清理** | 仪表盘统计卡 + 分类审阅 + 空间树图入口 |
| **工具箱** | 行式列表页：自启动管理 / 软件升级 / 注册表残留 / 扫描与更新 / 规则供给 / 定时调度 / 插件市场 |
| **设置** | 从抽屉升为独立视图（浮窗 / 隔离区仍用抽屉） |

### 重要新能力

- **Ctrl+K 命令面板**：全功能模糊搜索直达（5 视图 + 7 工具 + 3 动作，↑↓/Enter/Esc 键盘操作）
- **自启动管理首次获得 UI**（v4.0 服务补全）：签名状态色点、来源徽标、目标缺失标记、UAC 标记、可逆启停
- 顶栏胶囊导航与 🧰 浮层退役；⟳ 更新入口保留并改跳工具箱

### 质量验证

- 测试 500/500 全绿（新增导航注册表契约 3 用例）
- **真机 CDP 冒烟**：五区切换 / 仪表盘真实数据（45.69 GB / 307 软件 / 隔离区 3311）/ 自启动枚举 / 命令面板 16 条目 / 设置视图渲染 —— 全部通过
- 过程中揪出并修复：`.app` 布局方向覆盖遗漏导致主区高度塌陷（真机截图发现）

### 升级

4.1.1 → 5.0.0：应用内检查更新或系统通知 → 下载 → 重启并安装（GitHub + Gitee 双源可用）。装完默认进入浅色仪表盘；偏好深色请到 设置 → 外观 切换。
