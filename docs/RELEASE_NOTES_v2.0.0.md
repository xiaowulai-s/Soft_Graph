# SoftGraph v2.0.0 —— 软件图谱与磁盘清理工具

v2.0.0 是一次大幅升级：性能、原生能力、交付安全、体验与生态五个方向全面演进。

## 性能（M1）

- 软件发现 11.06s → **4.46s**，垃圾扫描 106.8s → **45~48s**，缓存命中 **1ms** 三项达标
- PowerShell 常驻会话池 + 扫描全环节并发化 + 体积延迟补算

## 原生能力双轨（M2）

- 增量扫描 **−65%**（按卷 mtime 水位，无原生模块同样适用）
- E6 反查索引 / API Set 问加载器 / 崩溃续扫 / 卷哨兵防脏写

## 交付安全（M3）

- **提权规范化**：提权通道只接收明确文件清单，双重校验 + hash 防篡改；「提权可清理区」白名单收紧（BUG-19）
- **本地诊断包**：写入前脱敏 + 零依赖 ZIP，全包用户信息零残留
- **路径健壮性**：中文/空格/emoji、507 字符长路径 16/16 通过；Windows 子树收紧（BUG-21）
- **压力测试**：5 万文件×3 轮 RSS 零泄漏；12000 依赖图谱 25ms
- **规则库在线更新**：HTTPS + Ed25519 签名 + 版本单调 + 毒丸防护
- 代码签名流水线就绪（正式证书到位后 15 分钟可切换）

## 体验（M4）

- **渐进渲染**：8001 节点真机实测 60 fps 零掉帧（近似布局 5ms）
- **图谱下钻与反向查询**：双击任意文件 → 引用它的软件 + 置信度，面包屑逐级返回
- **依赖 Diff**：新增 / 消失 / 置信度漂移三段式对比
- **交互式 HTML 快照导出**：悬停详情 / 缩放拖拽，零外链自包含

## 生态与审计（M5）

- **插件权限声明**：fs / network / powershell 声明制，用户授权后才运行
- **插件一键安装**：vm 沙箱校验 → 落盘 → 授权闭环，支持 https URL 或本地文件
- **审计日志**：五类删除动作逐文件留痕（append-only）
- **一键发布**：`npm run release` 固化构建→上传→校验全流程
