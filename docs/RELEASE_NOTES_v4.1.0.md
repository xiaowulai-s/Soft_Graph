# v4.1.0 Release 发布说明

**发布日期**：2026-10-25 · **tag**：`v4.1.0` · 测试 494/494 全绿

## 本版主题：组合 C 收官 —— S2 磁盘树图 / S3 一键启动 / S4 硬件脉搏 / S5 装机清单

接 v4.0.0（S1 自启动管理），本版完成《功能灵感地图》剩余四项，六大功能映射全部落地。

### S2 磁盘空间树图（windirstat 式可视化）

垃圾清理视图新增「**▦ 空间树图**」按钮：

- 输入任意目录 → **Squarified Treemap** 按面积呈现占用（手写算法，零依赖，含单测）
- 目录块**点击下钻**、面包屑返回上级；文件块可**送回收站**（可还原）/ **打开所在位置**
- 节点 2000 / 深度 4 上限，防大目录扫爆

### S3 一键启动

- 软件列表每项 **▶ 快捷启动** 按钮 + 右键菜单「启动应用」（`shell.openPath`）
- 图谱右键菜单新增「启动」
- **全局热键 Alt+G**：任意界面一键聚焦主窗并定位搜索框（设置 → 外观 → 全局热键，可关）

### S4 官方插件「硬件脉搏」（hw.pulse）

- CIM 查询 **CPU 负载 / 内存占用 / 系统盘可用空间**，bars 视图实时卡
- 需授权 PowerShell；查询结果 30s 状态缓存
- 插件市场即装即用（Gitee 直连）

### S5 装机清单

软件列表「**⬇清单**」一键导出：

- **CSV**：名称 / 版本 / 发布者 / 安装路径（表格归档）
- **PS1**：winget 批量静默安装脚本（换机/重装一键复刻）

## 已知边界

- S3b（浮窗「我的应用」卡）暂缓：浮窗插件契约暂无「点击动作」能力，列入插件 API v2（与插件沙箱化同批设计）
- 全局热键被其他程序占用时静默跳过（可在设置关闭后重开重试）
