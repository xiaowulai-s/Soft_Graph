# SoftGraph v3.1.1 —— 维护中心独立界面

## 新增：维护中心（🧰）

顶栏新增 🧰 按钮，打开独立的「维护中心」面板，四个标签页：

- **定时清理**：启用开关 / 执行周期（每天~每两周）/ 立即执行一次
- **软件升级**：列出 winget 可升级软件，支持**单个升级**和全部升级
- **隔离区管理**：彻底粉碎（双击确认，随机覆写后删除）
- **社区规则**：导入 Winapp2.ini（幂等，重复节自动跳过）

v3.1 的四个功能界面从设置抽屉整体迁入，设置抽屉只保留应用更新 / 规则更新源等全局设置。

## 修复

- **「重启并安装」按钮无效**：preload 误用 `ipcRenderer.send` 而主进程是 `ipcMain.handle`（通道无人监听）；改为 invoke 配对，并增加关窗兜底
- 发布脚本改**草稿发布**（draft → 附件全传完 → 公开），根除自更新 404 窗口

## 升级方式

- 3.1.0 用户：应用内「检查应用更新」→ 下载 → 重启并安装（3.1.0 的按钮有本版修复的 bug，若无效请**完全退出应用**，退出时自动安装）
- 3.0.3 用户：同上，或到 Releases 页手动下载
