## 项目一句话

Windows 桌面应用（Electron + Vue3 + TS）：软件图谱 + 磁盘清理 + 桌面浮窗 + 备份镜像。当前 **v6.2.2 已发布**（GitHub + Gitee，main = 550c6eb，测试 518/518 绿），用户安装版在 `C:\Software\SoftGraph`。

## 必读

1. **先读 `docs/16-项目交接文档-2026-11-08.md`**——架构、现状、15 条血泪坑、E2E 方法、待办全在里面。
2. 详细架构见 `docs/02-架构与实现.md`，发布流程见 `docs/05-推送与发布.md`，历版变更见 `docs/RELEASE_NOTES_v*.md`。

## 五条铁律（违反必翻车）

1. **theme.css 必须包在 `@layer base` 里**，否则 Tailwind v4 工具类全站静默失效。
2. **内嵌 PowerShell 只写 5.1 兼容语法**（禁 `??` 等PS7特性），否则功能静默返回空。
3. **Electron IPC 传参禁带 Vue reactive Proxy**（用 toRaw/JSON 展开），否则 DataCloneError 静默失败。
4. **可移动盘的 fs 操作必须异步 + withTimeout(12s)**，同步 fs 对抽/休眠 USB 会冻结整个主进程。
5. **发版必须升版本号新建 Release**，禁止覆盖旧 Release 附件（版本号不变 → 自动更新失效）。

## 环境速记

- 构建产物：`npx electron-vite build` + `npx electron-builder --win nsis portable --publish never`；发布 `npm run release`（附件须先放 `release/<版本>/`）；Gitee 同步 `GITEE_TOKEN=$(cat .keys/gitee-token) node scripts/sync-gitee.mjs <版本> --fresh`
- git push 时通时断：`unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY` + 重试循环 + `git ls-remote` 校验远端 SHA==HEAD
- 起 GUI：清 `ELECTRON_RUN_AS_NODE` 和 `NODE_OPTIONS`，加 `--no-sandbox`；CDP 截图须在 PowerShell **同一调用内**启动+截图
- 用户数据在 `%LOCALAPPDATA%\SoftGraph\`；备份任务存 SQLite kv 表 `backup:tasks`
