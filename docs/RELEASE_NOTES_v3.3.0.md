# SoftGraph v3.3.0 —— 储备三功能（相似图片 / 注册表残留 / 空目录）

v3.2 储备清单（docs/08 计划 P2-1/2/3）全部落地。

## 1. 相似图片盘点（P2-1，借鉴 Czkawka）
维护中心 → 「相似图片」标签页。感知哈希（aHash，9×8 灰度）+ 汉明距离分组，
扫描范围为图片/下载/文档目录。每组建议保留一张，其余「送回收站」（可还原）。

## 2. 注册表残留清理（P2-2，借鉴 BCU）
维护中心 → 「注册表清理」。枚举 HKCU/HKLM/WOW6432Node 卸载表，
列出「卸载程序已不存在且安装目录缺失」的死条目（多为一键卸载器/绿色软件残留）。
HKCU 条目直接删除；HKLM 条目弹 UAC。安全约束：只允许删除卸载表内的键。

## 3. 空目录检测（GC-18，hint，规则包 v6）
新 emptydir 算法：整棵子树无任何文件才命中，且只报告**最浅层空树根**
（整树删除一次带走，不重复报告树内深层目录）。根 = 用户库六目录，
清理无害且可还原。老用户通过规则热更新（v6 包）即可收到。
