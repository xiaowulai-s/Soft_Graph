## 过程中发现并修复的次生问题

1. **semHash 键序敏感**：`JSON.stringify` 保插入序，键序不同哈希不同 → 改排序键稳定序列化
2. **篡改样本容错**：非法 JSON 会使 JSON.parse 抛异常崩溃 → 退化原文哈希，篡改仍被拒
3. **ensureRules 契约重写**：旧「升级合并」测试套件按分区模型重写（4 用例：首装/迁移/幂等/损坏容错）
