# SoftGraph v3.0.0 —— 软件图谱与磁盘清理工具

v3.0.0 的主线是**把「能跑通」推进到「有真实数字、能长期维护」**：
覆盖率与样本库量化、原生增量能力打通、CI 端到端、浮窗生态扩展、注册表清理内核。

## 工程基座（M0）

- **单元测试覆盖率量化到 76.5%**（3329+/4351 行）：新增零依赖 sourcemap 还原器
  （`npm run test:cov`），把 esbuild 打包产物的 V8 覆盖率映射回 TS 源文件
- **PE 样本库 19 → 125 个**：12 组采集器覆盖系统 exe/dll、驱动、WinSxS、.NET、
  第三方 x64/x86；`npm run samples:verify` 125/125 零漂移
- 测试规模：**378 用例 / 84 套件全绿**

## 性能与原生能力（M1）

- **重复文件四级过滤**：在三段采样与全文件 SHA-256 之间插入扩展采样（16 段，
  约 1MB 读取量），并给各级哈希加并发。合成数据集 A/B：**−48%**，命中数完全一致
- **USN 变更记录级增量（B1）打通**：提权实测 `fsutil usn readjournal` 返回真实记录，
  据此修正解析器三处错误（USN 字段错位、原因标志位混入、缺失 ID 字段）
- `mapPool` 提取到 `@shared/util`，全链路统一并发口径

## 交付与回归（M2）

- **CI 接入 CDP 端到端**：`npm run e2e:ci` 自动启动应用 → 等调试端口 → 驱动真实交互
  → 关闭；CI 新增 `e2e` 作业并上传截图
- 真机回归：软件扫描 250 条目 · 图谱构建 · 垃圾扫描 13 分类 / 91.1 GB

## 浮窗生态（M3）

- **内置插件 7 → 11**：新增温度与风扇（三级 WMI 源）、电池与电源、
  网络连接（连接数 + TOP 进程）、专注计时
- **浮窗多实例（F4）**：每个实例独立插件组合 / 位置 / 尺寸 / 主题 / 穿透，
  可分布到多显示器；拖拽与悬停按来源窗口分发
- 向后兼容：老配置（无 `instances` 字段）自动折叠为默认实例，
  单实例行为逐字段等价（有专门断言钉死）

## 注册表清理内核（M4）

- 枚举三条 Uninstall 子树（HKLM 64/32 + HKCU）→ 残留判定 → 白名单校验
- 安全约束：白名单硬编码（只允许 `...\CurrentVersion\Uninstall\*`）、
  **先备份后删除**（备份失败即拒绝）、不提权时明确返回 `needsElevation`、
  JSON 快照含子键与值可完整还原
- 真机验证：252 个键，白名单 252/252 通过；收紧判定后仅 1 条真实残留

## 修复的缺陷

| 级别 | 缺陷 |
|---|---|
| 高 | **环境块膨胀导致 P/Invoke 能力静默全灭** —— 宿主环境块超 64KB 上限时 PowerShell `Add-Type` 失败，API Set 映射与占用检测不报错只返回空；现传白名单最小环境 |
| 高 | **注册表误报** —— 把 `SystemComponent=1` 的系统隐藏项（本机 37 条）与 Paint/截图工具等内置应用判成残留，删除会破坏系统注册 |
| 中 | 电池插件把「无电池」显示成「电量 0%」（`Number(null) === 0`）；USN 解析器 USN 字段错位一格 |
| 中 | 测试运行器整目录删除失败会打断测试链路（改为降级逐个清理） |

- UI 未接线：注册表清理界面、备份还原入口、浮窗实例管理界面
- 顺延项：A2 图标懒加载、A3 mtime 缓存、A7 依赖解析并行、I-11 FTS5 检索
