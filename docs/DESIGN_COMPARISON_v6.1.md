## 数据不可支撑的设计模块（诚实取舍）
1. 调度页「执行历史列表」——无历史记录存储，落地为上次执行 + 推算下次
2. 注册表页「备份还原面板」——备份还原功能在注册表 Tab（设置抽屉）已有，不重复
3. 相似图片「真实缩略图」——需图片缩放管线，当前哈希着色块代替（后续可加）
4. 图谱页「文件/边计数统计条」——需遍历图模型，避免每帧开销（后续可缓存）
