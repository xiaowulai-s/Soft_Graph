# SoftGraph v3.0.0 开发计划

> 定位：把 v2.0.0「功能齐备但留有缺口」推进到「可量化、可回归、可长期维护」。
> 三个关键词：**量化**（覆盖率 / 样本 / 增量都有真实数字）、**收口**（v2.0.0 顺延项全部落地）、**扩展**（注册表清理 + 浮窗生态）。
> 基线：v2.0.0（2026-09-17 发布，[Release](https://github.com/xiaowulai-s/Soft_Graph/releases/tag/v2.0.0)）

## 三、M0 工程基座（进行中）

### 3.1 G2 覆盖率量化

- 落点：`scripts/run-tests.mjs` 接入 `node --experimental-test-coverage`
- 输出：`.tmp/coverage/` + 控制台分层汇总（按 `packages/*` 分域）
- 门槛：先出真实数字，再针对 <50% 的模块补测；目标整体 ≥70%
- 注意：esbuild 打包后的覆盖率会映射到源文件，需验证 sourcemap 可用性；若不可行则改为「按模块统计用例覆盖」的人工对照表

### 3.2 G3 样本库扩容

- 落点：`tests/samples.ts`
- 采集维度：加壳（UPX / ASPack）、.NET（Framework / Core）、x86 / x64 / ARM64EC、便携软件、驱动（.sys）、零导入低层模块
- 目标：19 → 100+
- 回归：`npm run samples:verify` 零漂移
