# SoftGraph 功能梳理与新功能规划（v5.1~v6 路线）

> 2026-11-07 · 基于六项输入：真实高频使用 = 图谱 + 清理；其余近月未动；浮窗存在「开了不显示」bug；
> 形态偏好混合；新功能方向 = 软件深化 + 磁盘深化 + 健康管家 + 备份同步（用户点名）。

## 一、现状功能盘点与去留判决（19 项）

### 主线（升权）

| 功能 | 判决 | 理由 |
|---|---|---|
| 软件图谱 | **第一公民** | 真实高频 + 差异化核心；补「升级/卸载」动作后成为软件管理中枢 |
| 垃圾清理 | **第一公民** | 真实高频；把全部磁盘工具收拢到它的势力范围 |
| 仪表盘 | 保留 | 默认首页，但要为两条主线服务（见布局调整） |

### 调整（换位置 / 换组织）

| 功能 | 现位置 | 调整 | 理由 |
|---|---|---|---|
| 空间树图 | 清理视图按钮 | 保留原位 | 属磁盘主线 ✓ |
| 相似图片 | 工具箱→扫描与更新 | **移入清理域**（清理视图工具区） | 属磁盘主线，放软件管家组里是错位 |
| 大文件/重复/空目录 | 清理分类区 | 保留原位 | ✓ |
| 自启动 / winget 升级 | 工具箱 | 保留，且**接入图谱检查器**（选中软件可直接升级） | 软件主线 |
| 注册表残留 | 工具箱→软件资产 | 保留（卸载引导的附属） | 低频但与卸载强相关 |
| 装机清单 | 软件列表按钮 | 保留 | 换机场景 |
| 规则供给 | 工具箱 | **降权**：收进设置→规则区 | 纯配置项，不是"工具" |
| 插件市场 | 设置→浮窗 | 保留，随浮窗修复后重推 | 依赖浮窗可用性 |
| 应用更新 | 工具箱→系统 | 保留（⟳ 入口已有） | ✓ |

### 维持观察

| 功能 | 判决 |
|---|---|
| 定时清理（空闲窗口） | 保留自动化位，仪表盘动态已展示 |
| 审计日志 | 后台设施，不出前台 |
| 浮窗插件生态 | **修复 bug 后重推**；若修复后仍不用，降为实验特性 |

## 二、布局调整（v5.0.0 骨架上的小步走，不推倒）

```
活动栏五区不变：仪表盘 / 图谱 / 清理 / 工具箱 / 设置

调整 1｜清理视图 = 磁盘治理大本营
  分类审阅区下方「工具行」扩容：大文件 · 重复文件 · 空目录 · ▦空间树图 · 🖼相似图片
  （相似图片从工具箱迁入，磁盘能力一个视图找齐）

调整 2｜工具箱 = 软件管家
  行序：自启动管理 · 软件升级管家 · 注册表残留 · 装机清单（从软件列表补一个入口）
  规则供给迁出至设置；插件市场行保留

调整 3｜图谱检查器 = 软件管理动作中枢
  选中软件新增：「⬆ 升级此软件」（winget，已有数据）、「卸载引导」（拉起系统卸载串）

调整 4｜仪表盘加「常用软件」区
  最近启动/手动收藏的软件一键启动（图谱数据已有 mainExe，零后端成本）
```

## 三、浮窗 P0 bug（纳入下一版必修）

现象：开关打开后桌面不出现浮窗。修复排期在 v5.1 第一项，诊断方向：
窗口创建是否抛错（日志 scope float）、贴边/坐标计算在多显示器下的表现、
`alwaysOnTop + skipTaskbar` 在 Win11 的兼容、以及设置持久化里 enabled 状态与实际是否脱节。

## 四、新功能全景推荐表（按 价值 × 成本 排序）

| # | 功能 | 方向 | 价值 | 成本 | 形态 | 说明 |
|---|---|---|---|---|---|---|
| **N1** | **开发文件夹备份同步** | 备份（你点名） | ★★★★★ | 中 | 自动化 | 指定源目录 + 目标移动硬盘（按卷标/盘符识别），接入时增量拷贝 + 冲突跳过 + 任务日志；拔盘暂停、插盘续传 |
| N2 | 卸载引导 | 软件 | ★★★★★ | 低-中 | 被动 | 图谱检查器右键 → winget uninstall / 系统卸载串；生命周期闭环最后一环 |
| N3 | 安装包残留清理 | 磁盘 | ★★★★ | 低 | 自动 | 新 GC-19 规则：Downloads 里的旧 setup/msi/zip 安装包（按文件名特征 + 30 天未访问），默认不勾选 |
| N4 | 升级发现上仪表盘 | 软件 | ★★★ | 低 | 主动 | 待升级数进指标卡 + 系统通知（数据已有，纯接线） |
| N5 | 常用软件启动区 | 效率 | ★★★ | 低 | 被动 | 仪表盘显示最近启动/收藏软件，▶ 一键开 |
| N6 | 磁盘增长快照 | 磁盘 | ★★★★ | 中 | 主动 | 每次扫描存目录级快照入 SQLite；「什么在涨」对比视图；磁盘异常增长的告警基础 |
| N7 | 系统健康分 + 周报 | 管家 | ★★★ | 中 | 主动 | 垃圾/升级/自启动风险/磁盘余量加权打分；周报写日志+仪表盘展示 |
| N8 | 批量卸载 | 软件 | ★★☆ | 中 | 被动 | 勾选多个软件排队卸载（复用 winget 通道） |
| N9 | 智能清理策略 | 清理 | ★★☆ | 低 | 被动 | 保存自定义勾选组合为「策略」，下次扫描一键套用 |

## 五、推荐实施节奏

| 批次 | 版本 | 内容 | 工作量 |
|---|---|---|---|
| 第一批 | **v5.1.0** | 浮窗 bug 修复（P0）+ IA 布局调整四项 + N2 卸载引导 + N3 安装包清理（GC-19）+ N4/N5 低成本接线 | 1.5~2 天 |
| 第二批 | v5.2.0 | **N1 备份同步**（新活动栏区或工具箱头位，含设备检测/增量拷贝/日志） | 2~3 天 |
| 第三批 | v6.0 候选 | N6 快照对比 → N7 健康周报 → N8/N9 | 3~4 天 |

> 说明：N1 备份属于「动用户文件」的高责任功能——实施时默认**只增不改不删**（目标端同名文件跳过），
> 首版不做删除同步，避免误伤。移动硬盘未接入时任务显式暂停并在仪表盘提示。
