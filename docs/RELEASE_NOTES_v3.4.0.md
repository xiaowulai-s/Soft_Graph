# SoftGraph v3.4.0 —— 模块化导航外壳（三视图）

## 结构升级：导航由注册表驱动

应用骨架重构为**可扩展外壳**：顶栏导航由 `nav.ts` 模块注册表驱动，
未来新功能**追加一条注册项即可进入导航**，不再改动应用骨架。

三个平级主视图：

| 视图 | 职责 | 说明 |
|---|---|---|
| **软件图谱**（默认） | 认知：装了什么 · 文件属于谁 · 依赖关系 | 品牌与差异化所在 |
| **垃圾清理** | 行动：扫描发现文件 → 分类审阅 → 隔离清理 | 原「垃圾侧栏」升为全宽主视图 |
| **维护中心** | 管理：软件升级 · 隔离区 · 相似图片 · 注册表 · 规则 | 原 🧰 浮层升为页面模式 |

- 边界规则：扫描发现并清理「文件」→ 垃圾清理；管理「软件与系统状态」→ 维护中心；全局配置 → 设置
- 图谱视图切换用 v-show（画布状态保留，切回不重绘）；垃圾/维护视图按需挂载
- 维护中心支持 page/modal 双模式渲染（page 供主视图，modal 保留扩展能力）
- 定位随功能演进：产品叙事升级为「软件全生命周期管理」
