## 1. 项目是什么

**SoftGraph**——Windows 桌面应用（Electron + Vue3 + TS），定位「软件图谱 + 磁盘清理 + 备份镜像」三合一工具箱。

- **仓库**：`D:\Demo\Graph\softgraph`，远端 `origin = https://github.com/xiaowulai-s/Soft_Graph.git`（Gitee 镜像：`gitee.com/ABCHikS/softgraph-mirror`）
- **文档体系**：`docs/01~15` 编号文档（需求对照/架构/插件开发/验证报告/发布）+ 每版 `RELEASE_NOTES_vX.md`
- **用户数据**：`%LOCALAPPDATA%\SoftGraph\`（settings.json / data\softgraph.db(SQLite，kv 表存备份任务) / logs\*.jsonl / Quarantine / plugins）
- **安装位置（用户机）**：`C:\Software\SoftGraph\SoftGraph.exe`

## 2. 技术栈与架构

| 层 | 技术 |
|---|---|
| 构建 | electron-vite（根目录 `electron.vite.config.ts`，renderer 别名 `@shared`）+ electron-builder（NSIS + portable） |
| 前端 | Vue3 + Pinia + **Tailwind CSS v4**（`@tailwindcss/vite`）+ **shadcn-vue 组件**（自实现 `components/ui/`：Button/Card/Badge/Input/Separator + `lib/utils.ts` 的 `cn()`）+ d3-force |
| 主题 | `styles/theme.css`（**必须包在 `@layer base` 内**）+ `styles/tailwind.css`（`@theme inline` 把既有令牌桥接为 shadcn 语义色，深浅随 `data-theme` 切换） |
| 主进程 | `apps/desktop/src/main/`：services/（graph/junk/scan/backup/registry/winget…），IPC 走 `packages/shared/ipc.ts` 通道表 |
| 原生交互 | 纯 TS PE 解析器 + PowerShell（**只写 5.1 兼容语法**）+ PS 会话池 |
| 测试 | node:test，`npm test`（518 用例）；E2E 用 CDP（`--remote-debugging-port` + WebSocket，脚本在 `.tmp/*.mjs`） |

## 4. 关键坑（血泪史，接手必读）

### 4.1 代码级
1. **theme.css 必须包 `@layer base`**：Tailwind v4 工具类在 utilities 层，无层级样式级联上永远压过 utilities——不包则所有 Tailwind 类静默失效（截图前后一模一样的假象）
2. **内嵌 PowerShell 只写 5.1 语法**：`??` 运算符曾导致设备列表永远为空（U 盘检测不到的根因）
3. **Electron IPC 禁传 Vue reactive Proxy**：结构化克隆抛 DataCloneError 且易被静默吞掉——传参用 `toRaw()`/JSON 展开
4. **涉可移动盘的 fs 必须全异步 + 超时**：同步 `existsSync` 对断开/休眠的 USB 会冻结整个主进程事件循环（连超时计时器都停摆）
5. **手写 shadcn 组件禁用一次性 attrs 快照**：Input 必须用 `defineModel` + 响应式 `v-bind="attrs"`，否则选目录不回填
6. **NTFS 目录索引损坏会遗传**：幽灵条目删子目录清不掉，mkdir 持续 1392/UNKNOWN——改名挪走父目录再重建是绕过解（本次 E:\Demo 实战验证）

### 4.2 流程级
7. **覆盖 Release 附件不可取**：版本号不变 → electron-updater 判无更新，修复永远送不到用户（v6.2.0→v6.2.1 的教训）——必须升版本号新发 Release
8. **发布后必须真机走完整流程再交付**（v1 备份栽在没实测设备检测）
9. **GitHub 连通时通时断**：git push 用「重试循环 + 远端 SHA==HEAD 判据」；`unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY` + `git -c http.proxy= -c https.proxy=`；更新器 GitHub 源 504 会静默失败（**待办：Gitee 镜像 fallback**）

### 4.3 本机环境坑（沙箱/工具）
10. `ELECTRON_RUN_AS_NODE=1` 必须清除才能起 GUI；shell 泄漏的 `NODE_OPTIONS` 会让 packaged Electron 直接退出
11. bash 沙箱连不了 localhost——CDP 截图必须 PowerShell 同一调用内「启动→截图」完成（进程会随调用结束被回收）
12. `Start-Process` 前先 `Remove-Item Env:https_proxy/http_proxy`（大小写重复代理键会抛异常）
13. 宿主安全钩子会锁 electron-builder 的 `__uninstaller`（EBUSY）→ 分目标构建到新目录再拷回产物
14. 应用有**单实例锁**：重复 Start-Process 只会聚焦已有实例（新进程 HasExited=True 是假象）
15. PS 5.1 单元素数组会被展开成字符串（`.Pop()` 报错）——复杂遍历用 Python

## 5. E2E 验收方法（可复用）

1. `npx electron-vite build && npx electron-builder --dir -c.directories.output=release/<名> --publish never`
2. PowerShell 同一调用：清代理/env → `Start-Process win-unpacked\SoftGraph.exe --remote-debugging-port=92xx --no-sandbox` → 等 12s → `node .tmp/<脚本>.mjs <端口>`
3. 选择器注意：**按钮匹配前必须 `textContent.trim()`**；**按任务名锁定卡片须「含本任务名且不含其他任务名」排他祖先匹配**
4. 目录选择对话框用主进程测试钩子 stub：环境变量 `SG_E2E_PICKDIR="源|目标"`（仅 E2E 生效）
5. 截图 `Page.captureScreenshot` 落 `.tmp/*.png`，用视觉自检
