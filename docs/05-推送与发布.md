## 你需要在本地终端执行的一条命令

在能访问 GitHub 的终端（VPN / 代理正常）里：

```bash
cd D:\Demo\Graph\softgraph
git push -u origin main
```

首次推送会提示登录。两种方式：

1. **HTTPS + PAT（推荐）**：GitHub → Settings → Developer settings → Personal access tokens → 生成带 `repo` 权限的 token，密码位置粘贴 token
2. **SSH**：
   ```bash
   git remote set-url origin git@github.com:xiaowulai-s/Soft_Graph.git
   git push -u origin main
   ```

> 若仓库尚未创建：先在 GitHub 建一个**空仓库** `Soft_Graph`（不要勾选 Initialize with README），再执行上面的命令。

## 离线搬运方案（git bundle）

构建环境已生成本地仓库快照：`D:\Demo\Graph\Soft_Graph-1.0.0.bundle`（约 2 MB，含全部提交历史）。

在有网络的机器上执行任一即可：

```bash
# 方式一：从 bundle 克隆后推送
git clone D:\path\to\Soft_Graph-1.0.0.bundle Soft_Graph
cd Soft_Graph
git remote set-url origin https://github.com/xiaowulai-s/Soft_Graph.git
git push -u origin main

# 方式二：把 bundle 作为远程直接 fetch（已有本地仓库时）
git remote add bundle D:\path\to\Soft_Graph-1.0.0.bundle
git fetch bundle main:main
git push -u origin main
```

## 后续发布（Release 资产）

仓库入库的是源码（`node_modules/`、`out/`、`release/` 均已 gitignore，不入库）。二进制产物通过 Release 分发：

```bash
npm run pack:win          # 产出 release/1.0.0/
```

在 GitHub 仓库 → Releases → Draft a new release：

| 字段 | 值 |
|---|---|
| Tag | `v1.0.0` |
| Title | `SoftGraph v1.0.0` |
| 附件 | `release/1.0.0/SoftGraph Setup 1.0.0.exe`（NSIS 安装包） |
| 附件 | `release/1.0.0/SoftGraph-1.0.0-portable.exe`（免安装便携版） |
