# v5.2.0 Release 发布说明

**发布日期**：2026-11-07 · **tag**：`v5.2.0` · 测试 501/501 全绿 · 真机 12 页逐页冒烟通过

## 本版主题：全景重构 —— 12 个独立页面 + 侧栏带文字 + 四类交叉合并

按确认的设计稿实施（侧栏定稿 + 两段式页面样板）。

### ① 侧栏：图标 + 文本常显

- 宽度 150px（可一键折叠成 54px 纯图标），**12 个一级入口全部「图标 + 文本」**
- 全部条目统一规格：手绘 SVG 线性图标（18px / 1.7px 圆头描边 / 随激活态变色）+ 12px 统一文本 + 三组 10px 加宽字距分组标题（核心 / 软件管家 / 空间工具 / 系统）——零 emoji、零字符混排

全部页面统一「**状态总览卡 → 操作区**」两段式骨架（数字等宽、统一 page.css）。

### ③ 合并对照（四类交叉全处理）

- **升级三处合一**：唯一入口 = 软件升级页（图谱菜单与仪表盘不再重复提供管理操作，仪表盘只显计数）
- 相似图片 / 空间树图：各自唯一入口 = 独立页（清理头按钮删除）
- 扫描分类与工具理清：清理页 = 规则扫描；树图 / 相似图片 = 独立工具
- 定时调度：管理唯一入口 = 独立页；仪表盘只读展示

### ④ 🔴 浮窗 P0 继续深挖

5.1.0 修复后你的机器仍「完全无反应」（连首次通知都没有）→ 失败点在窗口创建**更早**阶段且异常被静默。本版：

- `new BrowserWindow` 全程 try/catch：**透明窗口创建失败自动降级实底窗口重试**（部分 GPU 环境不支持透明窗口的已知问题的标准解法）
- 开关全链路 try/catch：失败原因写日志（scope float）+ **直接 toast 上屏**，不再无反应
- 装上后如果仍看不到浮窗，设置里会显示具体错误原因——把那句话发我即可精准定位

### 升级

5.1.0 → 5.2.0：应用内 ⟳ 或系统通知 → 下载 → 重启并安装。装后重点验收：侧栏文字、12 页逐页点一遍、浮窗开关（如有问题看设置里的错误提示）。
